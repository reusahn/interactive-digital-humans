## Interpretation

This is strong second-joint causal evidence at one common base pose per checkpoint. It supports the same bounded cross-joint mechanism for the predeclared left-elbow perturbation in all three checkpoints.

It does **not** yet establish elbow pose robustness across the full predeclared schedules. The independent model-level unit remains checkpoint, `n=3`; frame tests are nested robustness diagnostics.

Raw displacement sums must not be pooled across sequences because sequence-specific scales differ.

## Important unresolved source-semantics caveat

Before publication-level claims or further expansion, the exact official `hugs_triplane` construction semantics should be audited at source commit `86ebe5522a384fc553f07f090b63a76dd4af8d33`.

Reason: the learned-LBS reconstructions for Parkinglot/Jogging were instantiated from the official decoder classes with strict state loading, but activation choice is not encoded in the state dict. Packaged configs include `human.activation` and an exact source audit is still needed to prove whether that config field is passed to `GeometryDecoder` / `DeformationDecoder`, what the decoder defaults are, and that the reconstructed forward exactly matches official `hugs_triplane` semantics.

This caveat does not invalidate the current numerical result by itself, but it is a foundational reproducibility check and should be resolved before the full elbow pose schedule is interpreted as final evidence.
