## Exact target definition

The target reconstructs HUGS `smpl_lbsweight_top_k` behavior:

1. build the subject-specific SMPL Vitruvian body from Parkinglot betas,
2. use the HUGS Vitruvian pose convention (`body_pose[2]=+1`, `body_pose[5]=-1`),
3. find K=6 nearest Vitruvian SMPL vertices for each canonical Gaussian,
4. apply the LBS-consistency gate `exp(-L1 / 0.02) > 0.9`,
5. apply spatial weighting `exp(-squared_distance)`,
6. normalize surviving neighbor weights,
7. interpolate 24-channel SMPL LBS weights.

## Interpretation

This is the first independent pretrained checkpoint in which the same qualitative precursor observed in Seattle is present: Gaussians anatomically assigned with high confidence to the contralateral upper body have almost no SMPL-derived K=6 left-wrist/hand support on average, while the learned HUGS deformation field assigns substantially larger cross-joint wrist/hand mass.

This is not yet a causal replication. No wrist perturbation has been applied in Parkinglot. The current evidence only establishes that the candidate learned cross-joint support pattern exists in a second independently pretrained model.

The learned maximum weight of ~0.249 is large enough that distribution/concentration should eventually be inspected, but it should not replace the mean/subset causal test.
