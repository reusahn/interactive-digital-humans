## Metric-definition clarification

Two locality scales had initially been mixed for the ankle probe.

Strict ankle/foot diagnostic:

```text
left_ankle + left_foot
```

Coarse semantic region:

```text
left_hip + left_knee + left_ankle + left_foot
```

The baseline ankle-z value of **26.57%** is therefore a fine joint-local diagnostic and counts propagation into knee/hip as outside. Under the full-left-leg target, the same +10 deg perturbation falls to **5.380455%**, and to **3.126863%** after dominant-joint confidence >= 0.9 filtering. The -10 deg result is nearly identical.

This supports hierarchical locality rather than a single binary leakage number.

### Interpretation

The learned checkpoint introduces small left-wrist/hand LBS components on Gaussians that remain overwhelmingly right-arm weighted. These learned cross-joint components are strongly associated with the observed contralateral displacement, especially in the high-confidence contralateral subset where the rank correlation is approximately **0.997**.

This is strong mechanism-level evidence, but it is not yet a causal ablation. The defensible statement is:

> In this Seattle/frame-0 wrist-z diagnostic, the pretrained HUGS learned deformation field introduces small cross-joint LBS components that are strongly associated with the amplified contralateral Gaussian response relative to the SMPL-derived K=6 target and SMPL-only control.

## End-of-day stopping point

This is a good stopping point for 2026-09-14. The mechanism candidate is now specific enough that the next experiment should be causal rather than another descriptive diagnostic.

### Next experiment: Step 14 counterfactual LBS ablation

Keep canonical Gaussians, pose transforms, geometry, and checkpoint state fixed, then compare the same left-wrist +10 deg perturbation under:

1. original learned LBS,
2. reconstructed K=6 target LBS,
3. learned LBS with only contralateral left-wrist/hand channels zeroed and renormalized.

Primary outcome: whether the contralateral displacement collapses toward the K=6/SMPL control when the learned cross-joint weights are removed.

If it does, this will provide direct causal evidence that learned cross-joint skinning weights drive the observed amplification.
