## Metric-definition clarification

Two locality scales had initially been mixed together for the ankle probe.

Strict ankle/foot diagnostic:

```text
left_ankle + left_foot
```

Coarse semantic region:

```text
left_hip + left_knee + left_ankle + left_foot
```

Thus the baseline ankle-z value of **26.57%** is a fine joint-local diagnostic and counts propagation into knee/hip as outside. Under the full-left-leg target, the same +10° perturbation falls to **5.380455%**, and to **3.126863%** after dominant-joint confidence >= 0.9 filtering. The -10° result is nearly identical.

This supports a hierarchical interpretation rather than a single binary leakage number.

## Step 13A — Reconstructed K=6 Gaussian-to-SMPL support mapping

Experiment 04:

- [K=6 Support Mapping README](../../experiments/04-k6-support-mapping/README.md)
- [K=6 support summary](../../experiments/04-k6-support-mapping/analysis/13A_k6_support_summary.csv)

The HUGS Vitruvian template and official K=6 neighbor weighting rule were reconstructed for all **472,958** saved canonical Gaussians.

### Reconstruction validation

- nearest-vertex exact match against the original saved probe = **0.9998583384**
- dominant-joint exact match = **1.0**
- maximum confidence error = **0.0**

This validates the reconstructed canonical SMPL support geometry extremely closely against the original diagnostic assignment.

### High-confidence nonlocal subset

- Gaussian count = **171,896**
- displacement sum = **4.617672**
- mean effective left-wrist + left-hand K=6 weight = **4.27e-6**
- displacement-weighted effective wrist/hand weight = **5.44e-7**
- fraction of displacement from points with wrist/hand K=6 influence > 1e-3 = **0.0**
- effective dominant-joint changed fraction = **0.0**

### High-confidence contralateral subset

- Gaussian count = **33,072**
- displacement sum = **4.163954**
- mean effective left-wrist + left-hand K=6 weight = **4.88e-7**
- displacement-weighted effective wrist/hand weight = **5.72e-7**
- fraction of displacement from points with wrist/hand K=6 influence > 1e-3 = **0.0**
- mean effective right-upper-limb K=6 weight = **0.995266**
- effective dominant-joint changed fraction = **0.0**

The top 5% highest-displacement high-confidence nonlocal subset shows the same pattern.

### Interpretation

The reconstructed K=6 support target does **not** explain the contralateral response through accidental direct left-wrist / left-hand skinning influence. The right-arm residual Gaussians are overwhelmingly supported by right-upper-limb SMPL weights while still moving under a left-wrist perturbation.

This rules out the simple hypothesis that the observed cross-body motion is caused by K=6 interpolation assigning substantial left-wrist support to the right arm.

## Critical implementation caveat discovered after Step 13A

The official NeuMan HUGS release configuration uses:

```text
human.name: hugs_trimlp
human.use_deformer: true
human.disable_posedirs: true
```

In the `use_deformer: true` branch, HUGS uses deformation-decoder **learned LBS weights** for the actual Gaussian deformation. The SMPL-derived K=6 weights are computed as a ground-truth / regularization target. Therefore Step 13A is a highly validated support-target diagnostic, but it is **not automatically the actual deformation-weight path** for the pretrained release model.

The exact saved checkpoint configuration used for the original probe must be recovered or verified before making a mechanism claim.

If the baseline used the standard release configuration, the next primary hypothesis is that the learned per-Gaussian LBS weights differ from their K=6 SMPL targets in the high-displacement contralateral subset.
