# Research Handoffs

These files preserve operational continuity between ChatGPT conversations and research sessions.

Use the dated daily log for the scientific record and the dated handoff for the exact continuation state.

## Workflow

At the end of each meaningful session:

1. update `research/logs/YYYY-MM-DD.md`,
2. create or update `research/handoffs/YYYY-MM-DD.md`,
3. commit compact tables, manifests, and SVG figures,
4. keep large raw NPZ files, datasets, licensed models, and checkpoints in Google Drive,
5. record Drive paths and all methodological corrections in the dated documents.
